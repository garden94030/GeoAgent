# Kinmen Satellite Image Analysis Workflow

This note records a practical QGIS workflow for analyzing the Kinmen SPOT-6
satellite image package. The original imagery is not committed to GitHub because
the files are large and may be subject to license restrictions.

Use `<KINMEN_DATA_DIR>` below as the local folder that contains the imagery,
QGIS projects, NDVI/NDWI outputs, scripts, manuals, and EULA files.

## Data Inventory

The package contains two observation dates:

| Date | Role | Multispectral | Panchromatic |
| --- | --- | --- | --- |
| 2025-12-08 | Pre-event / control date | `SRSL-I2603173` | `SRSL-I2603172` |
| 2025-12-29 | Post-event / comparison date | `SRSL-I2603175` | `SRSL-I2603174` |

The multispectral SPOT-6 imagery has four bands at about 6 m resolution:

| Band | Meaning | Typical Use |
| --- | --- | --- |
| Band 1 | Blue | True-color display |
| Band 2 | Green | True-color display and NDWI |
| Band 3 | Red | True-color display and NDVI |
| Band 4 | Near infrared | NDVI and NDWI |

The panchromatic imagery is about 1.5 m resolution and is useful for visual
interpretation, shoreline checks, and high-resolution comparison. The delivered
data is Level 3 orthorectified UTM imagery, so it should already align to real
map coordinates in QGIS.

## File Roles

| File Type | Purpose |
| --- | --- |
| `.qgz` | QGIS project files. Start with `金門水域.qgz` for the Kinmen project. |
| `.tif` | GeoTIFF rasters, including merged color imagery and NDVI/NDWI products. |
| `.bsq` + `.ers` | Original band rasters and metadata from the satellite package. |
| `.bin` + `.hdr` | Float NDVI/NDWI rasters generated by the analysis script for QGIS import. |
| `.aux.xml` | QGIS/GDAL auxiliary statistics and style metadata. Keep these beside rasters. |
| `.png` | Quick-look figures for reporting and visual comparison. |
| `.docx`, `.pdf` | Acquisition notes, manual, and license documents. |
| `.py` | Local scripts for band merging and NDVI/NDWI analysis. |

## Core Analysis Questions

The data is most suitable for four beginner-friendly analyses:

1. Before/after visual comparison.
2. Vegetation and bare-ground change using NDVI.
3. Water coverage and shallow-water pattern change using NDWI.
4. Hotspot mapping for places where index values changed strongly.

Use the results as evidence of physical surface or water-pattern change. Do not
claim a single cause from NDVI/NDWI alone. Tide, water turbidity, sun angle,
clouds, haze, seasonal vegetation, sensor processing, and image alignment can
all affect the values. Attribute possible military or operational meaning only
after comparing with independent evidence such as reports, vessel activity
records, local observations, or additional dates.

## NDVI And NDWI

NDVI highlights vegetation:

```text
NDVI = (NIR - Red) / (NIR + Red)
```

With SPOT-6 bands:

```text
NDVI = (Band 4 - Band 3) / (Band 4 + Band 3)
```

Typical interpretation:

| NDVI Value | Interpretation |
| --- | --- |
| `< 0.0` | Water, shadow, cloud shadow |
| `0.0 - 0.1` | Bare ground, built surface, paved area |
| `0.1 - 0.3` | Sparse vegetation |
| `0.3 - 0.6` | Vegetation, grassland, cropland |
| `> 0.6` | Dense vegetation |

NDWI highlights water:

```text
NDWI = (Green - NIR) / (Green + NIR)
```

With SPOT-6 bands:

```text
NDWI = (Band 2 - Band 4) / (Band 2 + Band 4)
```

Typical interpretation:

| NDWI Value | Interpretation |
| --- | --- |
| `> 0.3` | Clearer or deeper water signal |
| `0.0 - 0.3` | Shallow water, wetland, mixed pixels |
| `< 0.0` | Non-water surface |

## Run The Existing Python Analysis

From Terminal:

```bash
cd "<KINMEN_DATA_DIR>"
python3 ndvi_ndwi_analysis.py
```

If Python reports missing packages:

```bash
python3 -m pip install numpy matplotlib
```

The script writes charts, raw QGIS layers, and a text report to:

```text
<KINMEN_DATA_DIR>/output_analysis
```

The band-merge script requires GDAL. Since QGIS is installed, the easiest path
is usually to run the merge workflow from QGIS or from the Python environment
bundled with QGIS.

## QGIS Workflow

1. Open `金門水域.qgz`.
2. Add Google Satellite Hybrid or another basemap only as a visual reference.
3. Load the pre-event and post-event multispectral rasters.
4. Set both rasters to the same contrast stretch, preferably cumulative count
   cut around 2-98%.
5. Toggle layers on and off or use transparency to inspect visible change.
6. Load the NDVI and NDWI `.bin` files from `output_analysis`; QGIS should read
   the matching `.hdr` files automatically.
7. Style NDVI as single-band pseudocolor with a red-yellow-green palette and a
   value range around `-0.2` to `0.8`.
8. Style NDWI as single-band pseudocolor with a brown-blue palette and a value
   range around `-0.5` to `0.5`.
9. Create regions of interest as polygons for areas to compare.
10. Run zonal statistics for each region on pre-event and post-event index
    layers.
11. Export maps and tables for the research report.

## Suggested Research Outputs

| Output | Why It Helps |
| --- | --- |
| Before/after color map | Communicates visible surface and water differences. |
| NDVI change map | Highlights vegetation loss or new bare surfaces. |
| NDWI change map | Highlights water-pattern, shallow-water, or turbidity changes. |
| Region-of-interest table | Converts visual interpretation into measurable evidence. |
| Caveat section | Separates observed change from causal interpretation. |

## GitHub Sync Rule

For this project, keep licensed imagery and large rasters outside GitHub. Commit
only scripts, notes, small derived tables, and selected low-resolution figures
when their license allows publication.

Recommended sync after each analysis stage:

```bash
git status
git add docs/kinmen-satellite-analysis.md
git commit -m "Add Kinmen satellite analysis workflow"
git push origin main
```
